# TR-069 / CWMP — isp-control

Referencia para perfiles ACS estilo SmartOLT, compatibilidad OLT↔ONU/ONT y
el camino hacia el daemon ACS (fase posterior).

UI actual: **Ajustes → TR069**. VPN: Topología → **VPN**.

Scripts de aprovisionamiento cuando un modelo no crea la WAN de servicio
con el flujo genérico: [onu-model-provision.md](./onu-model-provision.md).

## Por qué VPN + ACS en `10.69.x.1:14501`

Las ONU no deben hablar con el ACS por Internet. El camino es:

1. ONU (IP de gestión en VLAN mgmt) → gateway MikroTik → túnel VPN →
   concentrador SaaS.
2. El ACS escucha en la IP del peer del túnel (`serverAddress`, p. ej.
   `10.69.69.1`) puerto **14501** (mismo default que SmartOLT).
3. Las rutas RFC1918 del cliente VPN permiten alcanzar redes LAN privadas
   (OLT, pools de mgmt ONU) desde el concentrador.

Sin túnel VPN configurado no se puede autocompletar una ACS URL usable.

## Flujo operador (fase 1 + pendiente)

```
VPN tunnel → Perfil TR069 → Adjuntar a OLT(s)
  → VLAN Management/VoIP en OLT + MikroTik
  → Pool IP mgmt ONU
  → En cada ONU: IP mgmt + aplicar perfil TR069 (OMCI)
  → ONU Inform → ACS (fase 2)
```

**Fase 1 (hoy):** crear/editar perfiles, adjuntar OLTs, ver parámetros
recomendados. Status CWMP = `offline` hasta existir el ACS.

**Fase 2:** daemon CWMP (Inform, Get/SetParameterValues), healthcheck ACS,
aplicar perfil a ONU vía CLI OMCI, Files (firmware/templates).

## Parámetros CWMP mínimos del perfil

Data model clásico **TR-098** (`InternetGatewayDevice`) y equivalente
**TR-181** (`Device`):

| Parámetro (TR-098) | Uso |
|--------------------|-----|
| `ManagementServer.URL` | ACS URL (`http://10.69.x.1:14501`) |
| `ManagementServer.Username` / `Password` | Auth CPE → ACS |
| `ManagementServer.PeriodicInformEnable` | `true` |
| `ManagementServer.PeriodicInformInterval` | segundos (default **300**) |
| `ManagementServer.ConnectionRequestUsername` / `Password` | Auth ACS → CPE |

El perfil de isp-control guarda solo ese mínimo y autocompleta valores
recomendados al crear (como SmartOLT).

Nota: muchas ONU HGU usan TR-181; el ACS debe aceptar ambos árboles. El
URL y credenciales son los mismos; cambian los paths de parámetros WAN/Wi‑Fi.

## Matriz OLT (objetivo SmartOLT)

| Vendor | Modelos | Notas |
|--------|---------|--------|
| ZTE | C220, C300, C320, C350/C350M | FW v1.2 / v2.0 / v2.1 — ver [zte-olt-c3xx.md](./zte-olt-c3xx.md) |
| Huawei | MA56xx, MA58xx | R009 → R018 (objetivo; integración OLT CLI pendiente) |

TR069 no gestiona la OLT por CWMP: la OLT **empuja** el ACS URL a la ONU
por **OMCI**. La OLT sí debe estar alcanzable (pública o VPN) para CLI/SNMP.

## Cómo se aplica el ACS a la ONU (OMCI — referencia fase 2)

Comandos varían por vendor; el perfil isp-control aporta URL + user/pass.

**ZTE (ejemplo HGU):**

```text
pon-onu-mng gpon-onu_1/x/y:z
  tr069-mgmt 1 acs <host:port> validate basic username <u> password <p>
  tr069-mgmt 1 state unlock
```

**Huawei:**

```text
ont tr069-server-profile add profile-id <id> url http://IP:PORT user <u> <p>
# interface gpon …
ont tr069-server-config <port> <ontid> profile-id <id>
```

**Otros (HALNy / genéricos):** perfiles `mgmt-mode tr-069 uri …` o
configuración web en la ONU si no hay OMCI.

Requisitos comunes en campo:

- Servicio TR069 / INTERNET+TR069 habilitado en la WAN o IP-host de mgmt.
- IP de gestión alcanzable desde el MikroTik (ping) antes de esperar Inform.
- Tras Inform, WAN puede provisionarse por **OMCI** o **TR069** (TR069
  favorece dual-stack IPv4+IPv6).

## Compatibilidad ONU/ONT

| Familia | Data model típico | Notas |
|---------|-------------------|--------|
| ZTE F6xx / HGU | TR-098 o TR-181 | Activar TR069 en lista de servicios WAN |
| Huawei EchoLife | TR-098 / TR-181 | Perfil tr069-server en OLT |
| Nokia / Calix / VSOL | Varía | Verificar OMCI + ACS URL HTTP (no solo HTTPS) |

Máxima compatibilidad práctica:

1. ACS URL en **HTTP** sobre IP del túnel (muchas ONU de campo no confían
   en CA públicas para el ACS).
2. Intervalo PeriodicInform moderado (300s).
3. Credenciales ACS y ConnectionRequest distintas.
4. No depender de opciones DHCP Option 43 al inicio; OMCI es el camino
   SmartOLT.
